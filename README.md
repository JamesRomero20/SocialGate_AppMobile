# SocialGate\_AppMobile

Un prototipo de aplicación Android diseñada para gestionar y controlar el acceso a Facebook e Instagram, fomentando el autocontrol digital y el uso responsable de las redes sociales.

-----

## 🎯 Propósito del Proyecto

El prototipo `SocialGate_AppMobile` se concibe como una aplicación independiente que actúa como intermediario entre el usuario y las redes sociales (específicamente Facebook e Instagram).

Su propósito principal es **gestionar y limitar el uso de dichas plataformas** mediante el monitoreo de tiempo y la restricción de acceso, según parámetros establecidos por el propio usuario. El sistema se integra con las funciones nativas de Android para supervisar la actividad de las aplicaciones y garantizar el cumplimiento de los límites establecidos, sin alterar el funcionamiento interno de Facebook o Instagram.

Este producto sirve como una herramienta de apoyo para **fomentar el uso responsable de las redes sociales** y mejorar el rendimiento académico, ayudando a los usuarios a desarrollar un mayor **autocontrol digital**.

-----

## ✨ Características Principales

El prototipo cuenta con las siguientes funcionalidades:

  * **Gestión de Cuentas:** Registro de usuario e inicio de sesión en la aplicación.
  * **Monitoreo de Actividad:** Supervisa el uso y el tiempo de pantalla dedicado a las aplicaciones de Facebook e Instagram.
  * **Control de Tiempo:** Permite al usuario establecer límites de tiempo diarios o específicos para el uso de estas redes.
  * **Horario Académico:** Integración de un horario para gestionar y priorizar el tiempo de estudio frente al ocio.
  * **Generación de Reportes:** Ofrece informes básicos sobre el tiempo de uso y la actividad registrada.
  * **Gestión de Permisos y Notificaciones:** Utiliza permisos nativos de Android para la supervisión y notifica al usuario cuando se alcanzan los límites establecidos.

-----

## 🛠️ Tecnologías Utilizadas

Este proyecto fue desarrollado utilizando las siguientes tecnologías:

  * **Lenguaje de Programación:** **Kotlin** (como lenguaje principal para el desarrollo nativo de Android).
  * **Base de Datos:** **SQLite** (para el almacenamiento local de datos del usuario, configuraciones, horarios y reportes).
  * **IDE de Desarrollo:** **Android Studio** (versión Hedgehog o superior).
  * **Plataforma:** **Android Nativo**.

-----

## ⚠️ Limitaciones del Prototipo

Es importante tener en cuenta que este es un prototipo y tiene ciertas limitaciones:

>   * **Versiones Soportadas:** El sistema está diseñado para funcionar exclusivamente con las **versiones oficiales** de las aplicaciones de Facebook e Instagram descargadas desde la Play Store.
>   * **Versiones No Soportadas:** El monitoreo **no es compatible** con las versiones "Lite" (Facebook Lite, Instagram Lite) ni con el acceso a través de navegadores web móviles.

## 🚀 Instalación y Ejecución

Para ejecutar este prototipo en tu entorno local, sigue estos pasos:

1.  **Clonar el repositorio:**

    ```bash
    git clone https://github.com/JamesRomero20/SocialGate_AppMobile.git
    ```

2.  **Abrir en Android Studio:**

      * Abre Android Studio.
      * Selecciona `Open` o `Open an existing project`.
      * Navega hasta el directorio donde clonaste el repositorio y selecciona la carpeta del proyecto.

3.  **Sincronizar Gradle:**

      * Espera a que Android Studio sincronice y descargue todas las dependencias de Gradle necesarias.

4.  **Ejecutar la Aplicación:**

      * Conecta un teléfono Android físico o utiliza un Emulador de Android (AVD).
      * Presiona `Run` (Shift + F10) en Android Studio para compilar e instalar la aplicación.
